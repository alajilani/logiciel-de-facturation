# Invoice Web App - Changelog

## Version 1.0.0 (Initial Release)

### Features
- ✅ Complete Django web application
- ✅ Client management (CRUD)
- ✅ Product management (CRUD)
- ✅ Invoice generation with auto-numbering
- ✅ Payment tracking
- ✅ Export to PDF (ReportLab)
- ✅ Export to Excel (OpenPyXL)
- ✅ Multi-country support
- ✅ EU VAT calculation
- ✅ Invoice discounts (Remise, Rabais, Escompte)
- ✅ Responsive Bootstrap UI
- ✅ Admin interface
- ✅ RESTful API endpoints
- ✅ Docker support
- ✅ PostgreSQL support

### Converted From
- Original desktop app: Python Tkinter + SQLite
- Current web version: Django + SQLite/PostgreSQL + Bootstrap

### Dependencies
- Django 4.2.0
- djangorestframework 3.14.0
- reportlab 4.0.9
- openpyxl 3.1.2
- Pillow 10.0.0
